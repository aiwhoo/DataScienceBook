Learning Objectives

By the end of this tutorial, you will be able to:

  • Define machine learning as a process of learning patterns from data.
  • Explain how machine learning uses multiple clues, or features, to make predictions.
  • Identify everyday examples of machine learning in apps, transportation, and smart systems.
  • Describe the three big ideas that structure this chapter: task type, evaluation, and modeling tools.

A Prediction Mystery: Can You Guess a Friend’s Heart Rate?

Imagine this scenario: yesterday, you walked 8,000 steps, while your friend walked only 3,000. Would your heart rates be the same? Probably not. Now add even more clues: your ages, genders, and how far you traveled. Suddenly, the problem becomes richer—and more interesting.

This is exactly the kind of situation where machine learning becomes useful. Instead of relying on a single clue, we use multiple pieces of information to make a smarter prediction.

NoteA Machine Learning Problem

A machine learning problem often begins with a question like: Given several clues, can we predict an outcome? In this chapter, that outcome is heart rate.

Teaching a Computer to Solve the Mystery

At its core, machine learning is about teaching a computer to learn from examples. Rather than programming every rule by hand, we give the computer data and let it discover patterns for itself.

Think about how you learned to recognize a dog. Nobody handed you a perfect rulebook. You learned by seeing many examples. Machine learning works in much the same way: the computer studies examples, detects patterns, and uses them to make predictions about new cases it has never seen before.

What is Machine Learning?

Machine Learning is when computers learn from data to make predictions without being explicitly programmed for every single scenario.

That does not mean the computer is “thinking” like a person. It means the computer is finding relationships in data. If those relationships are useful, the model can make a reasonable guess when new data appears.

TipInstructor Insight: Learning from Examples

A machine learning model is only as useful as the examples it learns from. Good data helps models find real patterns instead of random noise.

Why Machine Learning? It Is Everywhere.

Machine learning is not a futuristic idea. It is already embedded in many tools people use every day.

  • TikTok: Learns from your watch history, likes, and interactions to recommend videos.
  • Tesla: Uses computer vision models to detect pedestrians, lane markings, and obstacles in real time.
  • Smart Systems: Powers recommendation engines, fraud detection systems, and voice assistants.

These systems all rely on the same core idea: use past data to make a smart prediction or decision in the present.

What kind of problem are we solving? Are we predicting a number, or assigning a category?

2. Train/Test Split and Overfitting
