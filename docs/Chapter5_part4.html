When Linear Regression Falls Short

Linear Regression assumes the relationship between inputs and outputs follows a straight line. That assumption is sometimes useful—but real-world data is often more complicated.

Relationships in data may be curved, stepped, or highly nonlinear. When that happens, a straight-line model can miss important patterns.

This leads to an important question: What kind of model should we try when a line is not enough?

Enter the Decision Tree

A Decision Tree is a model that makes predictions by asking a series of yes/no questions about the data and splitting observations into branches.

Unlike Linear Regression, it does not try to fit one straight line across the entire dataset. Instead, it creates decision rules that divide the data into smaller and more specific groups.

Why Decision Trees Matter

  • Works for Regression and Classification: It can predict both numbers and categories.
  • Handles Nonlinear Patterns: It adapts more easily to complex relationships.
  • Easy to Visualize: The branching structure can often be drawn and interpreted step by step.
NoteDecision Rule

A Decision Tree makes predictions by repeatedly splitting data based on feature thresholds. Each split creates a new branch in the model.

Building a Decision Tree

To create a fair comparison, we use the same dataset from the Linear Regression example.

The workflow is familiar:

  1. Load and Prepare the Data
  2. Initialize the Model
  3. Fit the Model
  4. Generate Predictions
  5. Evaluate the Results

A typical scikit-learn workflow looks like this:

from sklearn.tree import DecisionTreeRegressor

tree_model = DecisionTreeRegressor(random_state=42)
tree_model.fit(X_train, y_train)
tree_predictions = tree_model.predict(X_test)

The Results Improved

In the slide example, the visual results improved. The scatter plot showed the predicted values sitting much closer to the actual values than they did with Linear Regression.

That visual “tightening” suggests that the Decision Tree captured the underlying pattern more effectively.

The evaluation metrics also improved:

  • MSE: 82
  • R²: 0.52

These numbers are much stronger than the earlier Linear Regression results.

The Numbers Back It Up

Why do these metrics matter?

  • Lower MSE means the model’s predictions are closer to the true values.
  • Higher R² means the model explains more of the variation in the data.

Compared with Linear Regression:

  • Linear Regression had a higher MSE and a lower R².
  • The Decision Tree had a lower MSE and a higher R².

That makes the Decision Tree the stronger model for this dataset.

TipInstructor Insight: One Model Does Not Fit Every Problem

A model that performs poorly is not a dead end. It is often a sign that the data needs a different modeling approach.

Linear Regression vs. Decision Tree

Here is the big comparison:

  • Linear Regression
    • Regression only
    • Assumes a linear relationship
    • Easier to describe with a formula
  • Decision Tree
    • Works for regression and classification
    • Handles nonlinear patterns
    • Easier to explain visually with branches

For this chapter’s dataset, the Decision Tree performed better on both major metrics.
